# GuiMenubar

> **Type**: `Class` | **Section**: `1.2.37`
> **Inherits from**: [`GuiVContainer`](GuiVContainer.md)

---

## 📖 Description

Only the main window has a menubar. The children of the menubar are menus. GuiMenubar extends the  GuiVContainer Object [page 286]. The type prefix and name are mbar.
