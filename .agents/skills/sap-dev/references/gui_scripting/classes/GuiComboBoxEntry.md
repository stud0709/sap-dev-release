# GuiComboBoxEntry

> **Type**: `Class` | **Section**: `1.2.14`

---

## 📖 Description

Members of the Entries collection of a GuiComboBox are of type GuiComBoxEntry.

---

## 📋 Properties

| Property | Access | Signature / Type | Description |
|:---|:---|:---|:---|
| **`Key`** | `Read-only` | `String` | Key value of the combo box entry. |
| **`Pos`** | `Read-only` | `Long` | Position of the combo box entry. The range is from 1 to the  number of entries in the combo box. |
| **`Value`** | `Read-only` | `String` | Value of the combo box entry. |
